Mi especialidad se centra en **desarrollo del lado del servidor, gestión de datos e integración de sistemas**:

- **Arquitectura de Bases de Datos** – Diseño de esquemas, optimización y Row Level Security

- **Autenticación y Seguridad** – Gestión de usuarios, control de acceso y protección de datos
- **Integración de Sistemas** – Conexión de aplicaciones, bases de datos y procesos empresariales
- **Infraestructura** – Despliegue, configuración y entornos de producción

Utilizo React y Next.js para construir interfaces que demuestren las soluciones backend, pero mi enfoque principal es el sistema que las respalda.
